# Veloxa SmartSchool logo: Register Path

The mark begins with a **class register**. Its vertical rule and three horizontal lines stand for the everyday records a school needs to keep clearly: attendance, class work and progress.

The top line rises toward a single dot. The dot represents a learner; the rising line represents using those records to notice a need, provide support and check progress. It reflects the product's working cycle: **record → understand → act → reassess**. The dot sits just beyond the line's end rather than on it, so the line points at the learner instead of touching them.

The open shape is intentionally simple so it remains recognizable on a phone, in a school sidebar and on printed material. Deep blue (`#1449a8`) connects it to Veloxa SmartSchool's current interface and conveys a calm, dependable school tool. It is one flat colour, so it also survives photocopying and stamping.

## Final artwork (version 2)

- [`veloxa-smartschool-logo.png`](veloxa-smartschool-logo.png): transparent 1024 × 1024 PNG for general use.
- [`register-path.svg`](register-path.svg): editable vector master. Every file in `variants/` uses this same geometry.
- [`review-sheet.png`](review-sheet.png): before and after, small sizes and every variant on one page.

`variants/` holds:

| Need | Files |
| --- | --- |
| Name beside the mark | `lockup-horizontal`, `lockup-stacked` (blue, `-white` for dark or blue backgrounds, `-black` for one-colour printing), each as SVG and PNG |
| Mark only, one colour | `register-path-white`, `register-path-black` (SVG and 1024 PNG) |
| App and home screen | `app-icon` (rounded tile, SVG, 512 and 1024 PNG), `app-icon-square` (full bleed, SVG and 1024 PNG), `apple-touch-icon-180.png` |
| Browser tab | `favicon.svg`, `favicon-16/32/48.png`, `favicon.ico` |

The favicon is a deliberately simplified cut (bar, two lines, dot with heavier strokes) because the full mark's thin gaps blur below about 24 px. Use the full mark from 24 px upward.

The wordmark is Google Sans (the font the app uses) converted to outlines, so the lockups need no font installed. "Veloxa" is set in Bold and "SmartSchool" in Medium.

## What changed from version 1

The first export is kept in `v1-before-fix/`. Version 2 separates the dot from the line (they overlapped into a lump), draws the rise as one smooth curve, gives all strokes the same weight, aligns the left ends of the lines, evens the spacing, and adds the lockups, reversed and one-colour files, app icon and favicon.

The meaning describes the intended design; it is not a claim that the software guarantees learning improvement or that the symbol has been legally cleared as exclusive. The app (`frontend/public/brand/`), the flyers and the proposal use this mark; the earlier Journey V icon is kept in `marketing/logos/superseded/`.
